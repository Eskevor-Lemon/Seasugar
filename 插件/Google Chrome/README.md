# Seasugar · Chrome 专名助手（0.1 试用版）

先保护 MLP 专名，再由用户手动使用 Chrome 的页面翻译。扩展不调用翻译接口、不需要 API Key，也不自动点击浏览器翻译菜单。`translate="no"` 与 `notranslate` 是兼容提示，不能保证浏览器每个版本都遵守。请先用短章节测试。

## 安装

1. 在仓库主页 Code → Download ZIP，完整解压。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择 `插件/Google Chrome`（包含 manifest.json 的这一层）。
4. 打开英文小说页面，点击扩展图标。更新文件后在扩展管理页点击“重新加载”，再刷新小说页。

## 使用

1. 若浏览器已经翻译，先点浏览器“显示原文”。
2. 选择内置精选表或自定义表。默认自动查找第一个 article / main / role=main；没找到或找错时选择“页面正文文本”。
3. 扫描并预览，逐处检查上下文、勾选名字，再点击“保护选中专名”。长名称优先，区分大小写，匹配完整词边界。
4. 使用浏览器自己的“翻译成中文”。若不可用，本扩展无法代替或连接该服务。
5. 悬停名字可看到原文。先用浏览器显示原文，再点“恢复本扩展替换”；如页面被重构而无法恢复，刷新网页可重载原文。

自定义表以 `英文 → 中文` 或无表头 TSV 编辑；支持 TXT、TSV、JSON 导入与 JSON 导出。JSON 支持网页导出的英译中 terms 格式，仅导入 source、target，不自动展开 aliases / variants；文件最多 1 MB，最多 3000 条。自定义与默认表相互独立。修改词表后需恢复旧替换再重新扫描。关闭弹窗后预览清空，但已应用标记仍留在网页，可以重新打开扩展恢复。

## 范围与限制

- 首版只支持英文网页到中文的专名辅助，不进行全文翻译或语义识别。Rarity 等必须人工判断。
- 仅处理当前页主框架的普通可见文本节点；不处理 iframe、Shadow DOM、PDF、图片、浏览器设置页、商店页、表单和代码块。跨 HTML 标签拆开的名字暂不匹配。
- 不自动监视动态页面，换章、加载更多后重新扫描。扫描最多 20000 个文本节点、约 100 万字符、1000 个匹配；单节点超过 5 万字符跳过。结果中会提示达到限制。
- 预览后已改变的节点会跳过，防止覆盖网站更新；恢复只处理本扩展持有的且文字仍为指定译名的标记，不覆盖被网页或翻译器修改的内容。不是全文撤销按钮。
- 预先替换中文可能影响句子语法与翻译质量，不能保证专名保护成功或文学质量。内置词表仅为精选，不是 Wiki 全表。

## 隐私与权限

仅申请 activeTab、scripting、storage；用户点击扩展后才临时访问当前页。不申请所有网站永久权限，没有远程脚本、统计或自建服务，也不发送正文。自定义词表和模式保存在 chrome.storage.local；原文匹配缓存只在页面内存中，刷新即清除。浏览器自带翻译的数据处理受浏览器服务商政策约束，扩展不承诺其离线或不上传。
