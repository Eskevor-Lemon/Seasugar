上传译名表

支持 Word（DOCX）、Excel（XLSX）、CSV、TSV 和 JSON，最大 5 MB、5000 条。表格列使用“原文、译名、别名、备注”，后两列可选。

先预览再导入；同名自定义词条可选择保留或替换。默认模式下导入后自动启用自定义覆盖。

导出与备份

导出当前翻译方向的 JSON 文件，可再次上传恢复。两个方向请分别导出。

备份个人修改请选择“自定义词条”。生效表包含所选模式中的默认词条，重新导入会成为自定义项。

下次打开，继续使用

保存成功后，词条和模式保存在此浏览器的本地存储中。使用同一浏览器、同一用户配置和同一网站地址，正常关闭或刷新后仍可读取，无需账号。

隐私模式、清除网站数据、换浏览器或网站域名变更时不能保证保留。请定期导出备份；这些修改只属于你，不会上传到 GitHub 或分享给其他使用者。
