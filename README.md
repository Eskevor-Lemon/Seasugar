# MLP Translation

英中小说翻译工作台：左侧原文、右侧可编辑译文，专名表优先，严格保留原文换行与空行。

## 已实现

- 英译中 / 中译英；随方向切换的「只翻译英文 / 只翻译中文」勾选框，默认开启。
- 专名表随时新增、编辑、删除、搜索；每次请求读取最新专名表。
- 导入 DOCX、XLSX、CSV、TSV、JSON；预览、编辑、勾选词条以及同名冲突处理。
- 不同翻译方向使用独立专名表；本地保存并导出 JSON 备份。
- 自定义文学翻译风格要求、别名和备注。
- 逐段翻译、进度、停止、错误提示、复制与 TXT 导出。
- 修改专名后按段落范围重译，保留范围以外的手工润色。
- 专名检查提醒、模型输出格式校验；拒绝空译文、额外分段与被截断的输出。
- GitHub Actions 自动测试、构建和 Pages 部署。

## 使用

1. 在「模型设置」填写服务商的 API 基础地址、模型 ID 和自己的 API Key。
2. 接口须兼容 Chat Completions（`/chat/completions`），并允许来自网页的跨域请求。基础地址和完整接口地址均可填写。密钥只保留在当前页面内存中。
3. 选择翻译方向，导入或填写专名表，在左侧粘贴原文，点击「开始翻译」。
4. 在右侧润色、复制或导出译文。关闭页面前请导出；本工具不保存原文与译文。

工具不提供模型额度，也没有绑定模型服务。是否免费、可用地域及调用限制取决于服务商。GitHub Pages 无法运行服务器代理；如果服务商禁止 CORS，需要另行部署自己的代理。

## 译名表格式

推荐两列或四列表格，首行为表头：

| 原文 | 译名 | 别名 | 备注 |
| --- | --- | --- | --- |
| Example Name | 示例译名 | Other Name;Short Name | 人名 |

- Word：使用表格；也可每行一条，用制表符或 ` → ` 分隔原文与译名。无法猜测任意散文式文档的结构。
- Excel：每个非空工作表使用相同列结构；支持常规共享字符串和内联字符串，不计算公式。
- CSV/TSV：UTF-8；CSV 支持引号、逗号与备注内换行。
- JSON：使用网页导出的格式，含 `direction` 和 `terms`。导入方向必须与当前设置一致。
- 别名用英文分号、中文分号或 `|` 分隔；只有原文和译名必填。
- 导入上限 5 MB、5000 条；解析在浏览器本地完成。同名词条默认保留旧值，可在预览中选择覆盖。别名冲突需要手动解决后再翻译。

## 分段、风格与语言保留

每个非空文本行视为一个段落，每段调用一次 API，保留原有换行、空行和首尾空白。超长单段（12000 字符以上）要求手动拆分。每次附带相邻原文片段供理解上下文，不维护整本小说记忆。

勾选语言限制时，模型被要求保留其他语言；取消勾选时，要求将正文中的其他语言一起译成目标语言。多语种识别、人物口吻、专名语义与忠实度仍由模型决定，不能保证完全准确。专名缺失检查只是提醒，不强行替换同形普通词。

第一版只有通用文学翻译约束和可编辑风格框，没有把未经完整核验的风格结论当作专用模型，也没有收录个人聊天、小说或译文文档。

重译依据当前页面中的原文与段落位置。改变原文、翻译方向，或改变译文行数后，不进行局部重译，以免错位覆盖；需要完整翻译或恢复对应结构。

## 本地开发

要求 Node.js 22.12+、pnpm 10+。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

浏览器回归（另开终端保持开发服务器运行）：

```sh
pnpm exec playwright install chromium
pnpm test:browser
```

Windows 可用 `BROWSER_CHANNEL=msedge` 环境变量选择已安装的 Edge。测试使用模拟 API，不消耗模型额度。涵盖导入、冲突、翻译方向、分段、局部重译、停止、密钥不落盘与窄屏布局。真实模型质量与 CORS 需在配置服务商后另行验证。

## GitHub Pages

在仓库 Settings → Pages → Build and deployment 中选择 **GitHub Actions**。推送 `main` 后，工作流会测试、构建并部署 `dist/`；也可在 Actions 中手动运行。构建使用相对资源路径，支持项目子路径部署。

## 数据

API Key 不写入浏览器存储、代码或日志。专名表、风格要求、API 地址和模型名称保存在当前浏览器的 localStorage。翻译时发送当前段、相邻原文片段、相关专名和风格要求至你配置的服务商。刷新后密钥、原文、译文清空，专名表和设置保留。
