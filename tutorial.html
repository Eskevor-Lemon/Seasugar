01 · TRANSLATION PACKET

如何使用翻译资料包

资料包把你的待翻译文本、相关专名与翻译要求整理成一份提示词。Seasugar 在本机生成资料，不调用模型；真正的翻译由你随后使用的聊天网页版完成。

  1. 进入首页，选择翻译方向。英文小说选“英文 → 中文”，中文文本选“中文 → 英文”。“只翻译英文 / 中文”勾选后，会要求模型保留其他语言片段。
  2. 粘贴待翻译文本。放入左侧“原文（输入）”框，保留原文段落和空行。这个框接收的是需要翻译的文本；不用先自行翻译。建议从几个段落开始测试，再按章节使用。
  3. 选择专名表和风格。右侧可选 Wiki 默认表或自己上传的自定义表；展开“翻译风格”，补充人物口吻、叙述要求或已确认的短篇双语样例。
  4. 点击“生成翻译资料包”。右侧会汇总翻译规则、输入中匹配到的专名和完整文本。没有出现的专名不会全部塞进去；同名多译会带上候选和语境说明。
  5. 复制到 DeepSeek。点击“复制资料包”，再点击“打开 DeepSeek”，在自己的账号中粘贴并发送。打开链接本身不会自动发送内容，也不需要把 API Key 填进资料包。
  6. 核对并保存译文。检查是否漏段、专名是否符合语境、人物口吻是否自然。资料包页面当前不接收模型回传，也不会自动校对译文；请在聊天页面或自己的文档中保存、修改结果。
什么时候需要重新生成？

修改输入、翻译方向、专名表或风格后重新生成。“复制资料包”和“导出 TXT”也会按最新设置重新生成。若浏览器不允许复制，请手动选中右侧内容复制。

长文章与多语言文本

单次输入最多 20 万字符，这不是聊天模型的可用长度保证。若资料包过长、模型漏译或输出中断，请按自然段或章节拆分，避免从句子中间截断。中文小说请选择“中文 → 英文”；英译中时不要为了减少请求而手工合并原文段落。

生成资料包不消耗 API 额度；聊天网页版的可用性与使用限制由平台决定。资料包会包含正文和相关词表，发送前请自行核对。

02 · API TRANSLATION

如何获取 API 并进行翻译

API Key 是服务商发给你的调用凭证，类似用于模型服务的钥匙。聊天网页版账号和 API 调用额度是两回事：能免费使用网页版，不代表 API 免费。Seasugar 不提供公共密钥或共用额度。

第一步：选择服务商，创建自己的 Key

选择在哪里获取在 Seasugar 中如何填写
Gemini 预设打开 Google AI Studio 的 API Keys 页面，登录账号，选择或创建有权限使用的项目，再创建并复制 Key。已有项目可能需先导入。在模型下拉框选择 Gemini 预设，地址与模型名自动填写，只填对应 Key。免费层、支持地区和项目计费状态以平台为准。
OpenRouter 预设登录 OpenRouter Keys 页面，创建 Key 并复制；查看模型页面的可用性与额度。选择网站提供的 OpenRouter 免费模型预设，粘贴 OpenRouter 的 Key。免费端点仍可能限流或暂时不可用。
DeepSeek 或其他兼容服务例如到 DeepSeek 开放平台注册 / 登录，在 API Keys 中创建 Key，并查看账户额度和费用。选择“连接其他翻译模型（自定义）”，分别填写 API 基础地址、模型名称和 Key。请使用服务商官方文档的当前值。

如果所在地区或网络无法使用某个平台，可以使用其他可访问的服务，或回到资料包模式。不要将网页聊天地址填进 API 地址栏。

第二步：在网页连接模型

  1. 点击右上角“API 翻译”，然后点击工作区的“模型设置”。
  2. 选择预设，或选择自定义连接。自定义服务需兼容 Chat Completions，并允许浏览器跨域请求。
  3. 以 DeepSeek 官方接口为例：基础地址填写 https://api.deepseek.com；模型 ID 按官方文档选择（核对时示例为 deepseek-flash）；Key 填开放平台创建的密钥。这里是配置示例，不保证服务商允许本站浏览器直接调用。
  4. 确认设置区域显示的接收地址是你选择的服务商。密钥只用于当前页面，刷新后清除；请勿把 Key 发给其他人或放入公开词表、截图和代码仓库。

第三步：翻译、校对与重译

  1. 选好翻译方向、专名表和风格，在左侧“原文”中粘贴文本，或使用“导入 TXT”。
  2. 先用两三个短段落试译，点击“开始翻译”。正文、相关专名和风格要求会直接发给所选服务商。
  3. 右侧会逐段出现结果；可以点击“停止”保留已完成部分。完成后可直接修改译文，再复制或导出 TXT。
  4. 修改专名后若只想重译部分内容，展开“更新已有译文”，填写起止段落并确认。所选段落的手工修改会被覆盖；空行不计作非空段落。原文或方向已改变时，请重新完整翻译。
连接失败时如何排查？

认证失败：核对 Key 与服务商是否匹配。模型不存在：检查模型 ID。额度不足或限流：查看账户余额、免费额度与请求频率。网络 / CORS 错误：确认地址正确、网络可达，且服务商允许浏览器访问；单靠换 Key 无法解决跨域限制。输出中断：缩短段落后重试，并保留已完成译文。

API 按服务商规则计费，重译会产生新的请求。使用免费预设前也应核对账户与模型页面，不要把“免费”理解为无限次数。

官方参考（2026-10-14 核对）：Gemini 密钥指南 · OpenRouter 入门 · DeepSeek 首次调用 API。界面、模型和额度可能调整，请以平台最新说明为准。

03 · YOUR GLOSSARY

如何修改 / 上传专名表

默认表与自定义表的区别

默认表来自小马灰机 Wiki 译名表：原配优先，缺失时使用国配；两者都没有则保留英文。默认表随网站版本更新；点击默认词条的“修改”会创建本地自定义覆盖，不会改动 Wiki 原表。自定义表可增删修改，保存在当前浏览器；“仅自定义”只使用自己的词表；“默认表＋自定义覆盖”会保留默认表，并优先使用你的自定义原文或别名对应的译名（匹配不区分大小写）。

直接添加或修改词条

  1. 点击右上角“专名表”，先选择翻译方向，再选择需要的词表模式。英译中与中译英的自定义词表分别保存。
  2. 点击“＋ 添加词条”，填写“原文”和“译名”，然后点击“保存”。已有条目点击“修改”后编辑并保存；不需要的自定义条目点击“删除”。
  3. 可选填别名与备注：别名用半角分号 ; 分隔；备注说明人物身份、作品范围或何时使用该译名。
  4. 搜索框可查找原文或译名。不要保留空白词条，也不要让同一原文或别名对应互相冲突的译名，否则生成或翻译可能被阻止。
  5. 改完后重新生成资料包；API 翻译的后续请求会使用新词表，已有译文不会自动改写。

从文件上传

支持 Word（.docx）、Excel（.xlsx）、CSV、TSV、JSON；不支持旧版 .doc / .xls、PDF 或截图。每个文件最大 5 MB，单次最多 5,000 条。推荐使用结构清楚的 Excel 或 CSV 表格：

原文译名别名备注
Twilight Sparkle暮光闪闪Twilight角色名；普通词义按上下文处理
Ponyville小马谷地点名称
  1. 至少准备“原文”和“译名”两列，推荐使用上面的表头。别名、备注可留空。Word 推荐使用真正的表格，Excel 避免合并单元格和无关说明行。
  2. 在专名表页面切换到正确翻译方向，到“上传译名表”栏位点击“选择文件”。
  3. 在确认窗口核对词条，可修改原文、译名，取消勾选不需要的条目。
  4. 同名冲突默认“保留已有译名”；希望覆盖时选择“使用导入的译名”，再点击“导入选中的词条”。
  5. 导入后检查词条数量与搜索结果。若文件注明的方向与当前方向不符，先切换方向再导入。

推荐：默认表＋自定义覆盖

选择“默认表＋自定义覆盖”，点击“＋”或上传小词表即可。例如添加 Ponyville → 小马谷，将覆盖默认的小马镇，其他默认词条继续生效。表格显示当前模式下全部生效词条，并标注默认或自定义来源，支持搜索与分页。别名也会覆盖相同名字的默认条目；未填写的其他别名不会自动跟随修改。删除覆盖项后恢复默认译名。

该模式与“仅自定义”共用同一方向的自定义词表。英译中覆盖不会自动反转为中译英，请按方向分别配置。在“导出与备份”栏位点击“导出自定义词条”只备份自己的条目；换设备后选择同一方向和覆盖模式再上传即可。资料包需要重新生成；API 已有译文需要重译才会更新。

如果希望复制整张默认表独立维护

选“默认专名表”后点击“导出当前生效表”，再切换到“自定义”并上传刚导出的 JSON。确认导入后即可编辑。注意：导入到自定义表时只保留每项的首选译名、别名和备注，不保留默认表的结构化多译候选；有歧义的词需要自己核对、调整。

备份与换设备

修改后点击“导出自定义词条”，将词表文件保存在自己的文件夹中。看到“已保存在此浏览器”后，同一浏览器、同一用户配置、同一网站地址下再次打开会自动读取。两个翻译方向请分别导出备份。自定义表不会自动同步账号或其他设备；清除浏览器站点数据、换浏览器或使用无痕窗口可能使原有记录不可用。在新设备中选好方向再上传备份即可。
